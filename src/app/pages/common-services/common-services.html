Common Services

Enumeration, authentication and attack techniques for commonly exposed network services.

SSH

SSH provides remote shell access. Focus on identifying the version, authentication methods, credentials and exposed keys before attempting access.

Enumeration Authentication SSH Keys Tunneling & Pivoting

FTP

FTP is primarily a file transfer service. Check for anonymous access, readable or writable directories and files that may expose credentials or other services.

Enumeration Authentication File Discovery

SMB

SMB exposes network shares and Windows resources. Look for anonymous access, readable or writable shares, sensitive files and credentials.

Enumeration Share Access Credential Hunting

HTTP / HTTPS

Web services expose applications, APIs and administrative interfaces. Start with technology identification, directories, virtual hosts and authentication points.

Initial Enumeration Directory Discovery Virtual Hosts HTTP POST Login Brute Force

SMTP

SMTP can reveal mail infrastructure, domains and valid users. Check supported commands and whether user enumeration is possible.

Enumeration User Enumeration Relay Testing

SNMP

SNMP is mainly used for information gathering. Check for exposed community strings such as public, which may reveal users, processes, interfaces and other system information.

Enumeration Community Strings Information Gathering

LDAP

LDAP provides structured directory information. Enumerate the naming context, users, groups and other objects that may help map the domain.

Base Discovery User Enumeration Authenticated Enumeration

RDP

RDP provides remote graphical access to Windows systems. Identify the service, security configuration and available authentication paths.

Enumeration Credential Brute Force Connection

Databases

Exposed databases can provide application data, credentials and sometimes direct access to the underlying system. Identify the database and authentication first.

MySQL MSSQL PostgreSQL
