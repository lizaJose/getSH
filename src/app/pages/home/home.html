// ABOUT

What is get.sh?

get.sh is a practical webapp designed to help you move from initial reconnaissance to full system compromise.

Instead of focusing on individual commands, the goal is to understand what to enumerate, why to enumerate it and what to do next.

// KNOWLEDGE_BASE

What's inside?

>_

Scanning

Discover hosts, identify open ports and enumerate exposed services using tools such as Nmap, RustScan, Masscan and Nikto.

◉

Common Services

Practical enumeration for SSH, FTP, SMB, HTTP, DNS, SMTP, LDAP and other services commonly found during penetration tests.

◈

Web Security

Web enumeration, directory discovery, authentication, common vulnerabilities and techniques for assessing web applications.

⚔

Exploitation

Turn enumeration into initial access by understanding vulnerabilities, attack surfaces and exploitation techniques.

↑

Privilege Escalation

Linux and Windows privilege escalation techniques, misconfigurations, credentials, services and common escalation paths.

◆

Active Directory

Domain enumeration, Kerberos, credential attacks, lateral movement, delegation and Active Directory attack paths.

⌁

Post-Exploitation

Credential access, lateral movement, pivoting and post-compromise workflows after obtaining an initial foothold.

/

Methodology

Practical decision-making workflows designed to answer the most important question during an assessment: what should I do next?
